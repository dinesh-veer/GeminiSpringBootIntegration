Gemini Chat

Gemini Model

The repository configures the Gemini chat model as: 

gemini-3.5-flash

Spring AI Integration

The project includes the Spring AI Google GenAI starter: 

<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-model-google-genai</artifactId>
</dependency>

Spring AI provides the application-level integration while the Google GenAI integration communicates with the configured Gemini model.

Configuration

spring:
  application:
    name: GeminiSpringBootIntegration
  ai:
    google:
      genai:
        api-key: ${GOOGLE_GEMINI_KEY}
        chat:
          model: gemini-3.5-flash

What This Example Demonstrates

  • Adding the Spring AI Google GenAI starter to a Spring Boot application.
  • Externalizing the Gemini API key through an environment variable.
  • Selecting a Gemini chat model through Spring Boot configuration.
  • Using Spring AI as the integration layer for Gemini chat services.
The repository's public README does not specify the controller class or a public HTTP endpoint. The documentation therefore focuses on the verified integration and configuration rather than assuming an endpoint contract.
