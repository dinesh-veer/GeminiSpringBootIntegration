Troubleshooting

API Key Not Found

If the application cannot authenticate with Gemini, verify that the environment variable is set.

echo $GOOGLE_GEMINI_KEY

Then restart the application after exporting the variable.

Wrong Model Configuration

Verify that the model configuration matches the repository: 

spring:
  ai:
    google:
      genai:
        chat:
          model: gemini-3.5-flash

Maven Build Problems

Try a clean build:

./mvnw clean package

Java Version

The repository explicitly configures Java 21. Verify your active Java version: 

java -version

Dependency Problems

The project uses Spring Boot 4.1.0 and Spring AI 2.0.0. If dependencies are resolved from an unexpected version, check the Maven parent and Spring AI BOM versions in pom.xml.
