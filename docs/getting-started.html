Getting Started

Follow these steps to run GeminiSpringBootIntegration locally.

Requirements

  • Java 21
  • Maven
  • Git
  • Google Gemini API key

Clone Repository

git clone https://github.com/dinesh-veer/GeminiSpringBootIntegration.git
cd GeminiSpringBootIntegration

Configure the Gemini API Key

The application reads the Gemini API key from the GOOGLE_GEMINI_KEY environment variable. 

export GOOGLE_GEMINI_KEY="your-gemini-api-key"
Do not commit the API key to source control. Keep credentials in environment variables or another secure secret-management mechanism.

Build the Application

./mvnw clean package

On Windows, use:

mvnw.cmd clean package

Run the Application

./mvnw spring-boot:run

Alternatively, run the generated Spring Boot JAR with Java after a successful build.

Verify

Once the application starts, use the application's chat integration entry point implemented in the source code. The public README describes the project as a Gemini chat-service integration but does not publish a specific HTTP endpoint, so this documentation intentionally does not invent one.
