Architecture

Overview

The application is a Spring Boot service that uses Spring AI as the integration layer between application code and Google's Gemini model.

Components

Spring Boot Application

Provides the application runtime and dependency injection environment.

Spring AI

Provides the abstraction used to integrate the application with the AI model.

Google GenAI Starter

Provides Spring Boot integration for Google's GenAI/Gemini model.

Gemini Model

The configured chat model is gemini-3.5-flash.

Design Goal

The project keeps the Gemini integration inside the Spring Boot application while using Spring AI to avoid coupling application code directly to low-level provider API calls.
