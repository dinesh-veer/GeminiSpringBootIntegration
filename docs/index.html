GeminiSpringBootIntegration

Spring Boot integration with Gemini AI using Spring AI.

This project demonstrates how a Spring Boot application can integrate with Gemini AI to consume chat services through the Spring AI Google GenAI integration.

Get Started →

Overview

GeminiSpringBootIntegration is a Java/Spring Boot example focused on integrating Google Gemini chat capabilities into a Spring application using Spring AI.

Features

Gemini AI

Connects the application to Google's Gemini chat model.

Spring AI

Uses Spring AI's Google GenAI starter for model integration.

Spring Boot

Runs as a standard Spring Boot application with Maven build support.

Externalized API Key

The Gemini API key is supplied through the GOOGLE_GEMINI_KEY environment variable.
