Examples

1. Configure Gemini

Set the API key before starting the application:

export GOOGLE_GEMINI_KEY="your-gemini-api-key"

2. Select the Gemini Chat Model

spring:
  ai:
    google:
      genai:
        chat:
          model: gemini-3.5-flash

3. Build and Run

./mvnw clean package
./mvnw spring-boot:run
