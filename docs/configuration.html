Configuration

Application Configuration

The project uses src/main/resources/application.yml.

spring:
  application:
    name: GeminiSpringBootIntegration
  ai:
    google:
      genai:
        api-key: ${GOOGLE_GEMINI_KEY}
        chat:
          model: gemini-3.5-flash

Configuration Properties

PropertyValueDescription
spring.application.name GeminiSpringBootIntegration Spring Boot application name
spring.ai.google.genai.api-key ${GOOGLE_GEMINI_KEY} Reads the Gemini API key from an environment variable
spring.ai.google.genai.chat.model gemini-3.5-flash Gemini chat model configured by the repository

Environment Variable

export GOOGLE_GEMINI_KEY="your-gemini-api-key"

Maven Configuration

The repository uses Spring Boot 4.1.0, Java 21, and Spring AI 2.0.0. 

<properties>
    <java.version>21</java.version>
    <spring-ai.version>2.0.0</spring-ai.version>
</properties>

Dependencies

  • spring-boot-starter-webmvc
  • spring-ai-starter-model-google-genai
  • Lombok (optional)
  • Spring Boot web MVC test starter for tests
